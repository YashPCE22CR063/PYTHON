PYTHON
This repository contains a collection of Python programs developed as part of academic coursework. Each script demonstrates fundamental programming concepts and algorithms, serving as practical examples for learning and reference.​

Contents
The repository includes the following Python scripts:​

Experiment_1A.py to Experiment_1E.py: Basic Python programs covering foundational concepts.

Experiment_2A.py and Experiment_2B.py: Programs focusing on intermediate-level topics.

Experiment_3A.py and Experiment_3B.py: Scripts demonstrating advanced programming techniques.

Experiment_4A.py to Experiment_4D.py: Applications of data structures and algorithms.

Experiment_5A.py and Experiment_5B.py: Programs related to file handling and exception management.

Experiment_6A.py and Experiment_6B.py: Object-oriented programming examples.

Experiment_7.py to Experiment_9B.py: Miscellaneous programs covering various topics.

Experiment_10A(merge_sort).py: Implementation of the Merge Sort algorithm.

Experiment_10B(selection_sort).py: Implementation of the Selection Sort algorithm.

BinaryTree.py: Program demonstrating binary tree operations.

heapSort.py: Implementation of the Heap Sort algorithm.

insertionSort.py: Implementation of the Insertion Sort algorithm.​
